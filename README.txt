# CREATIVA IA - PROYECTO COMPLETO

Este ZIP contiene el proyecto web actual de CREATIVA IA.

## Qué contiene

- /website/index.html
  Página web actual lista para subir a Netlify.

- /prompts/universal_project_memory_prompt.txt
  Prompt universal para continuar el proyecto en otra sesión, otra IA o con otro desarrollador.

- /assets/logos
  Carpeta para guardar logos.

- /assets/videos
  Carpeta para guardar videos.

- /assets/images
  Carpeta para guardar imágenes.

## Cómo usarlo en otra sesión de ChatGPT

1. Sube este ZIP.
2. Copia y pega el prompt universal.
3. Escribe: "Continúa trabajando este proyecto sin romper nada anterior."

## Cómo subir a Netlify

1. Descomprime el ZIP.
2. Entra a Netlify.
3. Sube la carpeta /website.
4. El archivo principal es index.html.
